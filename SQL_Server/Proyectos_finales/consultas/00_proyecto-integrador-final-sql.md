## Criterios de evaluación: Proyecto Final SQL Server

### 1. Correcto diseño del Modelo Estrella — 25 puntos

- Definición clara de la tabla de hechos, sus dimensiones y las relaciones de uno a muchos (1 a N).
- Uso de claves subrogadas y claves foráneas.

### 2. Implementación de Base de Datos (DDL) — 25 puntos

- Creación correcta de tablas, esquemas y restricciones (`PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`).
- Elección adecuada de tipos de datos (`DECIMAL`, `INT`, `VARCHAR`, `DATE`).

### 3. Carga y Limpieza de Datos (ETL) — 25 puntos

- Transformación y migración de datos hacia el modelo estrella.
- Inclusión y poblamiento de la tabla.
- Tratamiento adecuado de duplicados y valores nulos.

### 4. Consultas Analíticas y Entregables — 25 puntos

- Scripts SQL con `JOIN`, agrupaciones (`GROUP BY`) y agregaciones que respondan preguntas de negocio.
- Creación de vistas (`VIEWS`) analíticas.
- Script `.sql` ejecutable sin errores, junto con el diagrama visual del modelo estrella.
