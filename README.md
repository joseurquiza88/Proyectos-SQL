# 🗄️ SQL Projects & Queries


El repositorio reúne prácticas realizadas a partir de cursos, workshops y proyectos propios, aplicadas a diferentes datasets y problemas. Incluye más de 100 consultas sobre datos de comercio electrónico, ejercicios de análisis de ventas, limpieza de datos, creación de bases de datos e integración de SQL con Python. Incluye ejercicios de distintos niveles de dificultad, desde consultas básicas hasta técnicas avanzadas, además del diseño y la gestión de bases de datos relacionales.

## 🎯 Objetivo

Profundizar en SQL mediante la práctica continua, consolidar los fundamentos del lenguaje y desarrollar habilidades para trabajar con datos, desde consultas sencillas hasta operaciones más complejas de transformación y análisis.

---



## 🛠️ Herramientas

- **SQL:** consultas, transformación y análisis de datos.
- **PostgreSQL, MySQL y SQL Server:** gestión y consulta de bases de datos.
- **Python:** procesamiento e integración con bases de datos.
- **Jupyter Notebook:** exploración de datos y ejecución de código.
- **Git & GitHub:** control de versiones y documentación.

## 📂 Proyectos y prácticas 
### 🛒 Análisis de datos de Olist — SQL
Más de 100 consultas SQL desarrolladas con PostgreSQL para practicar y aplicar conceptos de SQL sobre un conjunto de datos de comercio electrónico de Olist. Incluye consultas básicas, intermedias y avanzadas, uniones entre tablas, CTE, funciones de ventana y funciones de ranking como RANK() y DENSE_RANK(), orientadas al análisis de pedidos, clientes, productos y ventas.

**Herramienta:**  PostgreSQL + Python

Este fue desarrollado como entrega final de un curso basico de sql.
